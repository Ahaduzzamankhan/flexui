# flexui

npm wrapper for the FlexUI 2.0 compiler.

```bash
npm install flexui
npx flexui init
npx flexui build --minify
```

The compiler itself is a Go binary. This package resolves the right precompiled
binary for your platform, verifies its checksum and runs it. Nothing is compiled
on your machine and no install script is required.

## Platform packages

| Platform | Package |
| --- | --- |
| Windows x64 | `@flexui/cli-win32-x64` |
| Windows ARM64 | `@flexui/cli-win32-arm64` |
| Linux x64 | `@flexui/cli-linux-x64` |
| Linux ARM64 | `@flexui/cli-linux-arm64` |
| macOS x64 | `@flexui/cli-darwin-x64` |
| macOS ARM64 | `@flexui/cli-darwin-arm64` |

If optional dependencies are disabled, install the platform package directly or
set `FLEXUI_BINARY` to a `flexui` executable.

## TypeScript API

The wrapper is written in TypeScript. Sources live in `src/`, compiled output in
`dist/` (generated by `tsc`; `npm install` builds it through `prepare`).

```ts
import { build, inspect, version } from "flexui";

await build({ minify: true, cwd: process.cwd(), output: "dist/flexui.css" });
const result = await inspect({ cwd: process.cwd() });
console.log(result.stdout);
```

| Export | Purpose |
| --- | --- |
| `build(options)` | Compile the project and write the stylesheet. |
| `watch(options)` | Start watch mode. |
| `inspect(options)` | Print resolved rules. |
| `version(options)` | Read the compiler version. |
| `run(args, options)` | Run the compiler with arbitrary arguments, capturing output. |
| `runInherit(args, options)` | Run with inherited stdio; returns the exit code. |
| `resolveBinary()` | Path and verification state of the resolved binary. |
| `optArgs(options)` | Map options to compiler flags. |

`RunOptions` covers `cwd`, `root`, `config`, `input`, `output`, `content`,
`safelist`, `minify`, `verbose`, `noCache` and `env`. Failed builds reject with a
`FlexUIError` carrying `exitCode`, `stdout` and `stderr`.

## Zero runtime dependencies

The published package has no `dependencies`. TypeScript and `@types/node` are
development-only.

Tabs

Arrow keys + Home/End
Click or focus a tab and use ← →, Home and End. The runtime keeps one tab in the tab order, updates aria-selected and hides inactive panels.
Declare the tablist with data-fui-tabs and standard role="tab" / role="tabpanel" elements. No generated CSS or custom element is required.
Each panel is linked with aria-controls and labelled by its tab. Activation is automatic on focus, so keyboard users never need a second key press.

Dropdown & popover

Native popover

Free shipping

Orders over $50 ship free in 2–4 business days. The runtime positions the popover, closes it on Escape or an outside click, and keeps aria-expanded in sync.

Trigger with data-fui-dropdown or data-fui-popover, pointing at a target element.

Toasts

Pause on hover

Toasts enter a polite live region, keep four at most, and pause their dismissal timer while hovered or focused. 

toast({
  variant: "success",
  title: "Workspace created",
  description: "The new workspace is ready."
});

Focus & keyboard map

A11y
  • Tab / Shift+Tab stay inside open modal dialogs.
  • Esc closes dialogs, menus and popovers.
  • ↑ ↓ move through menu and command items.
  • ⌘K / Ctrl+K opens the command palette anywhere.
  • Focus returns to the trigger after every dismissal.
The page uses native <dialog> and the popover API. The runtime adds behaviour, not a parallel widget model.

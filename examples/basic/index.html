The engine

A compiler, not a big stylesheet.

Every class you write becomes a resolved rule with a stable position in the cascade. Nothing ships that your markup does not use.

⚡

Native Go compiler

One static binary, six platforms, zero dependencies. Cold builds are measured in milliseconds because there is no JavaScript toolchain in the way.

◈

Deterministic output

Rules sort by context, utility order and variant rank. The same source always produces the same bytes — reviewable diffs, reproducible builds.

◎

Variants that compose

Responsive, state, structural, group, peer, dark, data, ARIA, supports, arbitrary selectors and container queries — nested in any order.

⌘

Arbitrary values, when a token is not enough

Brackets escape the scale without escaping CSS: any length, colour, gradient, grid template or custom property.

w-[350px]

h-[calc(100vh-80px)]

grid-cols-[250px_1fr]

✦

Typography system

A fluid type scale with semantic classes such as type-heading.

Workflow

Three commands, then write markup.

  1. 1

    Install

    npm install flexui — npm picks the binary for your platform.

  2. 2

    Initialise

    npx flexui init writes a config and an entry stylesheet. Nothing is overwritten.

  3. 3

    Build

    npx flexui watch rebuilds on change; ship with --minify.

Output

flexui.css 
@layer flexui.base, flexui.utilities;

@layer flexui.utilities {
  .mx-auto { margin-inline: auto; }
  .px-6 { padding-inline: 1.5rem; }

  @media (min-width: 768px) {
    .md\:grid-cols-3 {
      grid-template-columns: repeat(3, minmax(0, 1fr));
    }
  }
}

Utilities live in a cascade layer, so your own CSS always wins without specificity games.

Questions

Do I need Go installed? +

No. The compiler is cross-compiled for Windows, Linux and macOS and installed by npm as a platform package. Go is only needed if you want to build FlexUI from source.

Does it work without JavaScript? +

Yes. Styling is plain CSS. The optional runtime that will power dialogs and menus is a separate, tree-shakeable module and is not required for utilities.

How big is the generated CSS? +

Only rules your sources reference are emitted, plus the preflight reset you opt into. A stylesheet for this page — 400-odd classes, responsive variants included — is around twenty kilobytes uncompressed.

Can I use my own design tokens? +

Theme configuration is the next milestone. Today the built-in scales cover spacing, colour, type, radius, shadow, breakpoints and easing, and arbitrary values cover the gaps.
